# Сравнение статистических отчётов accuracy-бенчмарка

Инструмент сравнивает два JSON-отчёта accuracy test инструмента sgl-eval и проверяет, насколько статистически значимо различаются средние значения accuracy score.
Для этого используется t-критерий Уэлча. Цель тестирования - понять, действительно ли новый прогон отличается от эталонного или наблюдаемая разница может быть случайной.

---

## Установка

### Вариант 1 — виртуальное окружение (venv)

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Вариант 2 — Docker

Сборка образа:

```bash
docker build -t compare-reports .
```

Запуск (корневой каталог проекта монтируется в контейнер):

```bash
docker run --rm \
    -v "$PWD:/app/data" \
    compare-reports \
    --ref /app/data/evals/deepseek_ref.json \
    --test /app/data/evals/deepseek_test.json \
    --config /app/data/config.yaml \
    --output /app/data/result.json
```

---

## Формат входных данных

### JSON-отчёты (`--ref`, `--test`)

Каждый JSON-файл должен содержать:

```json
{
  "aggregate": {
    "pass@1": 0.9,
    "pass@1_sem": 0.006,
    "pass@1_std": 0.024
  },
  "n_repeats": 16,
  "num_examples": 30,
  "model": "Qwen3.6-27B-FP8",
  "name": "aime25"
}
```

### Конфигурация (`--config`)

YAML-файл с двумя уровнями значимости (`config.yaml`):

```yaml
alpha_conservative: 0.01   # 99% доверительный интервал
alpha_liberal: 0.05        # 95% доверительный интервал
```

---

## Запуск

```bash
python compare_reports.py \
    --ref   evals/deepseek_ref.json \
    --test  evals/deepseek_test.json \
    --config config.yaml
```

Параметры CLI:

| Параметр     | Обязательный | Назначение                                              |
|--------------|---------------|---------------------------------------------------------|
| `--ref`      | да            | JSON-отчёт, принимаемый за референс.                     |
| `--test`     | да            | JSON-отчёт, принимаемый за «новый»/тестовый прогон.     |
| `--config`   | нет           | YAML-конфиг с `alpha_conservative`, `alpha_liberal`.    |
| `--output`   | нет           | Сохранить результат в JSON-файл по указанному пути.     |

Разность всегда считается как `diff = test − ref` (test относительно ref),
поэтому роль `--ref`/`--test` существенна для односторонних p-value.

Пример запуска:

```bash
python compare_reports.py --ref evals/deepseek_ref.json \
    --test evals/deepseek_test.json --config config.yaml --output result.json
```

## Выходной формат

```json
{
  "ref":  { "source", "model", "name", "mean", "sem", "std", "n_repeats" },
  "test": { "source", "model", "name", "mean", "sem", "std", "n_repeats" },
  "diff":          0.0,
  "se_diff":       0.0,
  "t_stat":        0.0,
  "p_two_sided":   0.0,
  "p_worse":       0.0,
  "p_better":      0.0,
  "cis": {
    "conservative": { "alpha", "lower", "upper", "significant" },
    "liberal":      { "alpha", "lower", "upper", "significant" }
  }
}
```

## Интерпретация результатов

### p-values

Все p-values проверяют гипотезы о **средних** значениях `pass@1` двух прогонов:
`μ_ref` — среднее референса, `μ_test` — среднее теста.

| Метрика       | Альтернатива H1                 | Нулевая гипотеза H0        |
|---------------|---------------------------------|----------------------------|
| `p_two_sided` | `μ_test ≠ μ_ref` (прогоны различаются) | `μ_test = μ_ref`    |
| `p_worse`     | `μ_test < μ_ref` (test хуже)    | `μ_test ≥ μ_ref` (test не хуже) |
| `p_better`    | `μ_test > μ_ref` (test лучше)   | `μ_test ≤ μ_ref` (test не лучше) |

Маленькое p-value означает «наблюдаемые данные маловероятны при H0», то есть
свидетельство **против** H0 и **в пользу** соответствующей H1.

| Метрика       | Что означает                                                   |
|---------------|----------------------------------------------------------------|
| `p_two_sided` | Вероятность при верной H0 (`μ_test = μ_ref`) увидеть разность не меньшую по модулю, чем наблюдаемая. |
| `p_worse`     | Вероятность при верной H0 (`μ_test ≥ μ_ref`) увидеть снижение `test` относительно `ref` не меньше наблюдаемого. |
| `p_better`    | Вероятность при верной H0 (`μ_test ≤ μ_ref`) увидеть рост `test` относительно `ref` не меньше наблюдаемого. |


### Доверительные интервалы

ДИ строится для разности `diff = test − ref` и, в отличие от p-value, отвечает
не только на «есть ли различие», но и на «насколько оно велико» — это оценка
**величины эффекта** вместе с её неопределённостью.

- **Направление (значимость).** Если 0 внутри `[lower; upper]` — нулевая
  гипотеза не отвергается. Весь интервал выше 0 — test значимо **лучше**, весь
  ниже 0 — значимо **хуже**.
- **Величина.** Границы задают диапазон правдоподобных значений истинной
  разности. `[-0.05; -0.02]` = «test хуже ref на 2–5 п.п. `pass@1` на этом
  датасете»: верхняя граница — минимальное правдоподобное ухудшение, нижняя —
  максимальное.
- **Точность.** Ширина интервала отражает неопределённость: узкий ДИ — оценка
  величины точная, широкий — направление понятно, а «насколько» — нет. Центр
  совпадает с точечной оценкой `diff`; точки внутри не равновероятны (центр
  правдоподобнее краёв).
- **Уровни значимости.** Интервалы могут строиться для нескольких уровней значимости:
  они напрямую следую из параметра `confidence` при вычислении доверительных интервалов
  По умолчанию используются уровни значимости `conservative` (99%) и `liberal` (95%)


#### Уровни значимости и ошибки I и II рода

Понятие уровней значимости напрямую связвно с понятиями ошибки I и II рода:

- **Ошибка I рода (ложная тревога):** заявить «различие есть», хотя на самом
  деле его нет.
- **Ошибка II рода (пропуск):** заявить «различия нет», хотя оно на самом деле
  есть.

`alpha` (Значение 1 - `confidence`) по определению равен вероятности ошибки I рода — это порог, ниже
которого p-value считается «слишком невероятным при H0». Между ошибками
обратный размен: чем ниже `alpha`, тем реже ложные тревоги, но тем легче
пропустить реальный (особенно слабый) эффект.

| Уровень | `alpha` | Ошибка I рода (ложная тревога) | Ошибка II рода (пропуск эффекта) |
|---------|---------|-------------------------------|-----------------------------------|
| `conservative` | 0.01 | ниже | выше |
| `liberal` | 0.05 | выше | ниже |

То есть:

- **`conservative` (99%).** Если разницы на самом деле нет, ложную тревогу мы
  получим в среднем лишь в **одном тесте из 100**. Зато реальный, но слабый
  эффект легче пропустить — тест строже.
- **`liberal` (95%).** Ложная тревога случается чаще — примерно в **5 тестах
  из 100** (при отсутствии реальной разницы), но и реальный эффект ловится
  чаще: тест чувствительнее.
